# Code of conduct

## The short version

Be decent to people. Assume the person you are replying to is acting in good faith and
knows something you do not.

## What that rules out

Harassment, insults, and personal attacks. Sexualised language or imagery. Publishing
someone's private information. Sustained disruption of a discussion. Dismissing a bug
report or a question because of who asked it — the person filing a confused issue is
telling you something true about the project.

Technical disagreement is not covered by any of the above. Argue about the design as much
as you like.

## Scope

This applies in the issue tracker, in pull requests, and anywhere someone is representing
the project.

## Reporting

Report privately through GitHub: the repository's **Security** tab →
**Report a vulnerability** opens a private thread visible only to the maintainers. It is
not what that form was built for, but it is the private channel this project has, and a
report sent there will be read.

Reports are handled by the maintainers, who may warn, remove content, or block an account.
This is a small project — there is no committee and no appeals process, so the honest
commitment is that a report will be read, taken seriously, and kept private.

This is a condensed statement of the standards in the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. Where it is silent, the Covenant is the reference.
